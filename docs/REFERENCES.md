# REFERENCES

## Anti-AI-slop / interface craft

- Impeccable — Slop catalog  
  https://impeccable.style/slop/

Key ideas used:
- avoid cardocalypse,
- avoid decorative gradients/glow/glass,
- avoid generic icon tiles,
- use explicit design-system tokens,
- create real type hierarchy,
- avoid overused generic defaults,
- use spacing and hierarchy rather than decoration.
